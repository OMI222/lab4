## Описание

Программа собирает сведения о компьютере, анализирует характеристики и выполняет мониторинг системных ресурсов.

## Файлы проекта

- `inventory.py` — сбор информации о системе, CPU, RAM, дисках и сети, формирование рекомендаций.
- `monitor.py` — мониторинг CPU, RAM, DISK и батареи.
- `passport_WIN-TJGLN343PHF.json` — технический паспорт компьютера.
- `monitor_log.csv` — журнал измерений.

## Параметры варианта №4

- Интервал: 1 секунда
- Количество измерений: 40
- Порог CPU: 60%
- Порог RAM: 75%
- Порог DISK: 80%
- Дополнительная метрика: заряд батареи

## Запуск

Установка зависимости:

`pip install psutil`

Запуск инвентаризации:

`python inventory.py`

Запуск мониторинга:

`python monitor.py`

## Результаты

При тестировании загрузка CPU достигала 63,8%, превысив порог 60%.

При нагрузке на RAM использование памяти увеличилось с 47,6% до 59,4%.

Программы успешно создали технический паспорт в формате JSON и журнал мониторинга в CSV.
